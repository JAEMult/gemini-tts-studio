# Gemini TTS Studio

App local em HTML puro (sem backend/servidor) para gerar narração via Gemini TTS API, com perfis de voz por canal e geração em lote.

Este repositório existe só como **backup portátil** do arquivo `gemini-tts-studio.html` — é nele que o botão "💾 Salvar Backup no GitHub" do próprio app grava, e é dele que o atualizador da versão portátil baixa a versão mais recente (`raw.githubusercontent.com`, sem token).

Uso normal: baixe a pasta portátil (`.zip`) e rode o launcher — veja o `LEIA-ME.txt` de dentro dela.
